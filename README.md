# charan-SQL-Bankingproject
Banking database project using MySQL/db fiddle

This project is based on a simple Banking Management System created using SQL. I worked on this project to improve my understanding of SQL and practise writing queries using a banking-related dataset.

The database contains information about customers, bank branches, accounts, transactions, cards, and loans. I created tables, inserted sample records, and wrote SQL queries to retrieve, filter, combine, and analyse the data.

Database Tables

The project includes the following 10 tables:

cust_info – Stores customer details.

branch – Contains bank branch information.

account_types – Stores different types of bank accounts and their interest rates.

trans_channel – Contains transaction channel details.

acc_info – Stores account balances, opening dates, and account statuses.

acc_holders – Connects customers with their bank accounts.

transxs – Contains deposit and withdrawal transaction details.

cards – Stores debit and credit card information.

loans – Contains customer loan details.

loan_payments – Stores loan repayment and EMI information.

SQL Concepts Covered

I used this project to practise the following SQL concepts:

Basic SQL: CREATE TABLE, INSERT, SELECT

Filtering: WHERE, AND, OR, NOT

Operators: IN, NOT IN, BETWEEN, IS NULL, IS NOT NULL

Sorting and Limiting: ORDER BY, ASC, DESC, LIMIT

Aggregate Functions: COUNT(), SUM(), AVG(), MIN(), MAX()

Grouping: GROUP BY, HAVING

Joins: INNER JOIN, LEFT JOIN, RIGHT JOIN

Combining Results: UNION, UNION ALL

Subqueries: Nested queries and derived tables

Advanced Queries: ANY, Common Table Expressions (CTEs)

Window Functions: OVER(), PARTITION BY, RANK(), ROW_NUMBER()

String Functions: UPPER(), LOWER(), CONCAT(), LENGTH(), SUBSTRING(), INSTR(), LOCATE()

Pattern Matching: LIKE

Date Functions: DATE_FORMAT(), INTERVAL
