# charan-SQL-Bankingproject
Banking database project using MySQL/db fiddle

This project is based on a simple Banking Management System created using SQL. I worked on this project to improve my understanding of SQL and practise writing queries using a banking-related dataset.

The database contains information about customers, bank branches, accounts, transactions, cards, and loans. I created tables, inserted sample records, and wrote SQL queries to retrieve, filter, combine, and analyse the data.
